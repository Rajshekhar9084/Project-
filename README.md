   # 🧮 Basic Calculator in C

This is a simple **console-based calculator** written in C.  
It allows the user to perform basic arithmetic operations in an interactive menu-driven way.  

---

## ✨ Features
- Addition  
- Subtraction  
- Multiplication  
- Division (with zero-check)  
- Modulo (remainder)  
- Power (using `pow()` function)  
- Exit option to quit  

---

## 🚀 How to Run
1. Compile the program:
```bash
gcc calculator.c -o calculator -lm
