# 🖥️ C Programming Projects

This repository contains beginner-friendly C projects:  
1. **Basic Calculator**  
2. **Number Guessing Game**  

---

## 1️⃣ 🧮 Basic Calculator
A simple console-based calculator that performs arithmetic operations.

### ✨ Features
- **Addition**  
- **Subtraction**  
- **Multiplication**  
- **Division** (with zero-check)  
- **Modulo** (remainder)  
- **Power** (using `pow()` function)  
- **Exit option**  

### 🚀 How to Run
```bash
gcc calculator.c -o calculator -lm
./calculator

## 2️⃣ 🎯 Number Guessing Game
A fun guessing game where the computer generates a random number between **1 and 100**, and the player tries to guess it.

### ✨ Features
- Generates a **random number** each time  
- Provides hints (**higher** / **lower**)  
- Shows the **number of attempts**  
- Beginner-friendly project in **C**  

### 🚀 How to Run
```bash
gcc guessing_game.c -o guessing_game
./guessing_game
